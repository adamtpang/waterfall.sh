about the project

One local board. A cheaper first rung.

waterfall.sh is an independent software project for people who use coding agents across several repositories and do not want every prompt to begin with their most expensive model.

What waterfall.sh does

The waterfall.sh router classifies a prompt locally as free, split, or Claude work. A routine task can go to the cheapest capable model in OpenRouter’s live-priced catalog, while a split task returns its difficult remainder with the lower-cost output already attached.

The waterfall.sh board gives that routing system a local desktop surface. Project folders become tabs, active agent sessions can keep running while another project is visible, and the same local settings connect the board to supported command-line agents.

What is available

The repository contains a Python command-line router, a local dashboard, Claude Code hooks, a response cache, usage and savings ledgers, and desktop application sources. A native Windows v0.1.0 installer is published; the command-line installer also supports Windows, macOS, and Linux.

The current limits are documented publicly. The Windows package is not code-signed, native macOS and Linux desktop packages are not available, and automatic skill self-triggering has converted only a small measured share of nudges into real routes.

Identity and operation

waterfall.sh is maintained as an independent software project through the public adamtpang GitHub repository and X account linked below. The project identity does not claim that waterfall.sh is an incorporated company or a local business.

The public website is a static product and documentation site hosted on Vercel. Purchases leave waterfall.sh for a Stripe-hosted payment page, while downloads, source code, and issue reporting use the public GitHub repository.
