# Research report

Answer with real, current, sourced facts. A report with explicit gaps is better than
a smooth report padded with guesses.

## 1. Check existing work

Search the current conversation and project for prior research before starting over.
Reuse it only when it is still current and sourced. State what is stale or missing.

## 2. Define the question

Write one sentence describing what the report must answer. If the request can mean
several materially different things, ask one focused question before doing expensive
research.

Use direct research for one bounded question. Use independent research tracks for a
topic with several separable parts, if the host supports them.

## 3. Apply the evidence rule

- Report a fact only when a real source supports it.
- Add dates to facts that can change.
- Prefer primary sources: official documentation, first-party datasets, standards,
  repositories, filings, and original research.
- If credible sources disagree, show the disagreement.
- Label estimates as estimates and explain where they came from.
- Say “no reliable public data” when that is the honest result.
- Never invent a missing number, name, date, quote, or citation.

## 4. Write the report

Lead with the direct answer. Keep facts specific and the structure easy to scan.
Call out uncertainty near the relevant claim. End with a Sources section containing
direct links to the pages used.

Do not cite search-result pages when a primary page is available. Do not use em
dashes.

## 5. Save only durable work

If the research will be reused, offer to save it as a dated Markdown file. Do not
turn every short answer into a document.
