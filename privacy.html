privacy notice

What this website does with data

waterfall.sh is a static public website. We use cookieless page analytics to understand which public pages are useful. The website has no account, newsletter, or contact form.

Hosting

The waterfall.sh website is hosted on Vercel. Requests therefore pass through Vercel’s infrastructure, which may process ordinary request information such as an IP address, user agent, requested path, timestamp, and security or delivery metadata under Vercel’s own terms and privacy notice.

Page analytics

PostHog processes public pageviews in its US region, including the page path and basic browser and device information. Tracking is configured without analytics cookies or person profiles. It does not record sessions, form inputs, query strings, URL fragments, or referrer paths. Network requests necessarily expose an IP address to the receiving service. See PostHog’s privacy notice.

External links

The purchase button opens a Stripe-hosted payment page. Download, source, and issue links open GitHub, while the public social contact link opens X. Those services receive information only after a visitor chooses to follow the relevant link, and each service applies its own privacy practices.

The waterfall.sh site does not embed Stripe, GitHub, or X scripts into its pages. The site also does not attempt to read a visitor’s local waterfall.sh installation, local model keys, local project folders, or local usage ledgers.

Contact and sensitive information

The waterfall.sh contact page points to public third-party channels rather than collecting a message itself. Visitors should never put API keys, payment details, private repository content, or other secrets into a public GitHub issue or public social post.

Questions about this notice can be raised through the same public contact paths. Because this page has no form, following a contact link does not send anything until the visitor chooses an action on the destination service.
