Contact waterfall.sh

waterfall.sh does not collect support requests through a website form. Use one of the project’s existing public channels so the maintainer can see the context and respond there.

GitHub issues

Use the public repository’s issue tracker for reproducible bugs, installation problems, documentation corrections, or feature requests. Do not include API keys, payment details, private repository content, or other secrets.
