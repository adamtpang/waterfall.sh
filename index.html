how it falls

A real sequence, not a model guess.

Each stage narrows the prompt, uses a capable lower-cost model, or hands the hard remainder to the model you picked for difficult work.

  1. 01

    Classify

    A local classifier scores the prompt with no API call and picks a free, split, or Claude route.

  2. 02

    Cascade

    Routine work goes to the cheapest capable model in OpenRouter's live-priced catalog.

  3. 03

    Fall back

    If a model is down, rate-limited, or returns nothing usable, the next ranked candidate takes over.

  4. 04

    Surface

    Only the difficult remainder reaches Claude or Grok, with the cheaper output already attached.

install

Runs on your machine.

The board binds to 127.0.0.1. This website never connects to your localhost.

CLI

Windows, macOS, and Linux. Installs to ~/.waterfall and merges the Claude Code hooks with a backup.

curl -sSL https://raw.githubusercontent.com/adamtpang/waterfall.sh/main/install.py | python3

Windows app

v0.1.0 release as an NSIS installer or MSI. Unsigned, so SmartScreen warns once.
