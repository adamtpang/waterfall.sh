Picked by what you actually want, not your OS. The product runs on your machine. The site never talks to someone else's localhost.

I just want the CLI

curl -sSL https://raw.githubusercontent.com/adamtpang/waterfall.sh/main/install.py | python3

Works on Windows, macOS, and Linux alike, and it is the only path on macOS and Linux. Clones to ~/.waterfall, wires the hooks, puts `waterfall` and `watertop` on PATH.

I want the native desktop board

waterfall_0.1.0_x64-setup.exe

Download v0.1.0 for Windows (NSIS 3.0 MB, or the MSI). Cascade panel, one shared OpenRouter key, agent launchers. Not code-signed, so SmartScreen warns on first launch: More info, then Run anyway. macOS/Linux packaging isn't started.

git clone https://github.com/adamtpang/waterfall.sh
