How it falls

every rung is a real HTTP call, not a browser tab →
Rung 01

Classify

A local, zero-API classifier scores each prompt for complexity and decides: free, split, or straight to Claude. No round trip needed just to decide.

Rung 02

Cascade

The routine part is auto-routed to the cheapest capable model on OpenRouter's live-priced catalog — selected fresh each time, not hardcoded to a model that got expensive or deprecated.

Rung 03

Fall back

If a call fails or the response is thin, it falls to the next rung. A waterfall, not a single point of failure.

Rung 04

Surface

Only the hard remainder reaches Claude — with the free model's output already stitched in, ready to paste. Your 20x plan lasts the whole day instead of the first hour.
